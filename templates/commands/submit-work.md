# /submit-work

Execute the submit-work phase of the specoven workflow.

## Usage

```
/submit-work
/submit-work [WI-ID]
```

## What this command does

Reads `.agents/skills/submit-work/SKILL.md` and executes the full submit-work skill for the current (or specified) work item.

## Prerequisites

See `.agents/skills/submit-work/SKILL.md` for required inputs.

## Output

Artifacts produced by the submit-work phase. See the skill definition for details.
