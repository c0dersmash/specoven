# /propose-work

Execute the propose-work phase of the specoven workflow.

## Usage

```
/propose-work
/propose-work [WI-ID]
```

## What this command does

Reads `.agents/skills/propose-work/SKILL.md` and executes the full propose-work skill for the current (or specified) work item.

## Prerequisites

See `.agents/skills/propose-work/SKILL.md` for required inputs.

## Output

Artifacts produced by the propose-work phase. See the skill definition for details.
