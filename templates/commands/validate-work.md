# /validate-work

Execute the validate-work phase of the specoven workflow.

## Usage

```
/validate-work
/validate-work [WI-ID]
```

## What this command does

Reads `.agents/skills/validate-work/SKILL.md` and executes the full validate-work skill for the current (or specified) work item.

## Prerequisites

See `.agents/skills/validate-work/SKILL.md` for required inputs.

## Output

Artifacts produced by the validate-work phase. See the skill definition for details.
