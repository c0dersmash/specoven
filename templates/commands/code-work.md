# /code-work

Execute the code-work phase of the specoven workflow.

## Usage

```
/code-work
/code-work [WI-ID]
```

## What this command does

Reads `.agents/skills/code-work/SKILL.md` and executes the full code-work skill for the current (or specified) work item.

## Prerequisites

See `.agents/skills/code-work/SKILL.md` for required inputs.

## Output

Artifacts produced by the code-work phase. See the skill definition for details.
