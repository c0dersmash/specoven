# /verify-work

Execute the verify-work phase of the specoven workflow.

## Usage

```
/verify-work
/verify-work [WI-ID]
```

## What this command does

Reads `.agents/skills/verify-work/SKILL.md` and executes the full verify-work skill for the current (or specified) work item.

## Prerequisites

See `.agents/skills/verify-work/SKILL.md` for required inputs.

## Output

Artifacts produced by the verify-work phase. See the skill definition for details.
