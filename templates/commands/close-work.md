# /close-work

Execute the close-work phase of the specoven workflow.

## Usage

```
/close-work
/close-work [WI-ID]
```

## What this command does

Reads `.agents/skills/close-work/SKILL.md` and executes the full close-work skill for the current (or specified) work item.

## Prerequisites

See `.agents/skills/close-work/SKILL.md` for required inputs.

## Output

Artifacts produced by the close-work phase. See the skill definition for details.
