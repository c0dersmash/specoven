# /design-work

Execute the design-work phase of the specoven workflow.

## Usage

```
/design-work
/design-work [WI-ID]
```

## What this command does

Reads `.agents/skills/design-work/SKILL.md` and executes the full design-work skill for the current (or specified) work item.

## Prerequisites

See `.agents/skills/design-work/SKILL.md` for required inputs.

## Output

Artifacts produced by the design-work phase. See the skill definition for details.
