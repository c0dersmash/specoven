# /feedback-work

Execute the feedback-work phase of the specoven workflow.

## Usage

```
/feedback-work
/feedback-work [WI-ID]
```

## What this command does

Reads `.agents/skills/feedback-work/SKILL.md` and executes the full feedback-work skill for the current (or specified) work item.

## Prerequisites

See `.agents/skills/feedback-work/SKILL.md` for required inputs.

## Output

Artifacts produced by the feedback-work phase. See the skill definition for details.
